📸 Phase 2: Product Images - Implementation Guide

🎯 Objective

Add high-quality images to all 19 Makita battery products with optimization and lazy loading.

✅ Prerequisites

  • [ ] Python 3.x installed
  • [ ] Node.js installed
  • [ ] Product images collected (or use placeholder)

    • 📋 Step-by-Step Guide

    Step 1: Prepare Product Images

    Option A: Download Real Product Images 
    # Download from Makita official site or distributor

    Recommended resolution: 1200x1200px minimum
    

    Format: PNG or JPEG
    Option B: Use Placeholder (Temporary) 
    # Create simple placeholder images
python scripts/create_placeholder_images.py
    Recommended Image Structure: 
    public/product-images/makita-batteries/
├── BL4020/
│   ├── main.webp        # Primary image
│   ├── front.webp       # Front view
│   ├── side.webp        # Side view
│   └── charger.webp     # With charger
├── BL4025/
│   └── main.webp
├── ...
└── placeholder.webp     # Fallback image

    Step 2: Run Image Processing Script

    # Process and optimize all images
python scripts/add_battery_images.py
    What this does:
  • ✅ Converts images to WebP format
  • ✅ Generates 3 sizes (thumbnail, medium, large)
  • ✅ Compresses images (80% quality)
  • ✅ Updates products.json with image paths
  • ✅ Creates backup of products.json

    • Step 3: Update Product Data

    The script automatically updates products.json, but you can also manually add: 
    {
  "id": "makita-batteries:191L29-0",
  "sku": "191L29-0",
  "media": [
    {
      "url": "/product-images/makita-batteries/BL4020/main.webp",
      "role": "main",
      "type": "image",
      "format": "webp",
      "sizes": {
        "thumbnail": "/product-images/makita-batteries/BL4020/main-150.webp",
        "medium": "/product-images/makita-batteries/BL4020/main-300.webp",
        "large": "/product-images/makita-batteries/BL4020/main-600.webp"
      }
    }
  ],
  "imageUrl": "/product-images/makita-batteries/BL4020/main.webp"
}

    Step 4: Test Image Component

    npm run dev
    Visit http://localhost:3000/batteries and verify:
  • ✅ Images load correctly
  • ✅ Lazy loading works (images load as you scroll)
  • ✅ Hover zoom works
  • ✅ Fallback to placeholder if image missing

    • Step 5: Verify All Products

    # Check which products have images
python scripts/verify_battery_images.py
    Expected output: 
    ✅ 191L29-0: BL4020 - Image found
✅ 191B36-3: BL4025 - Image found
...
Total: 19/19 products have images

    • 🐛 Troubleshooting

    Images Not Showing?

  • Check image path: /product-images/makita-batteries/BL4020/main.webp
  • Verify file exists in public folder
  • Check browser console for errors
  • Clear browser cache

    • Slow Loading?

  • Check image file size (should be < 100KB for thumbnails)
  • Verify WebP format used
  • Check lazy loading is enabled

    • Zoom Not Working?

  • Check ProductImage component props
  • Verify CSS hover styles
  • Test in different browsers
