    • 🐛 Troubleshooting

    Cart not persisting?

  • Check localStorage is enabled
  • Verify CART_STORAGE_KEY is correct
  • Check browser console for errors

    • Prices wrong?

  • Verify VAT_RATE = 0.21 (21%)
  • Check product has price and price_incl_vat
  • Use cartHelpers.js functions

    • Context not working?

  • Verify CartProvider wraps your app
  • Check you're using useCart() inside components
  • Import from correct path
